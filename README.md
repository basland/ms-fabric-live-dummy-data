# ms-fabric-live-dummy-data
A repository containing a dummy data generator for Maxo Fabric that keeps your dummy data up to date with construction wholesale data.

The goal of this repository is to have a mechanism inside Microsoft Fabric that will create dummy data on a set schedule. Every night, you can schedule a bunch of Python scripts that will populate a database, a lakehouse, or a warehouse with information that mimics a real-life ERP and CRM system. Therefore, you can more easily test and validate your processes, scripts, and everything inside Microsoft Fabric.
